# 中國高校論文模板指南（中國高校論文模板指南）

## 本指南存在的原因

中國高校論文模板（.docx）的結構模式與西方模板差異顯著。假設西方慣例（Heading1/Heading2/Normal）的 agent 會反覆失敗。本指南記錄了中國模板中的實際模式。

## 常見 StyleId 模式

### 模式 A：數字 ID（中文 Word 模板中最常見）

| 樣式用途 | styleId | w:name | w:basedOn |
|--------------|---------|--------|-----------|
| 正文 Normal | `a` | "Normal" | — |
| 默認段落字體 | `a0` | "Default Paragraph Font" | — |
| 一級標題（章標題） | `1` | "heading 1" | `a` |
| 二級標題（節標題） | `2` | "heading 2" | `a` |
| 三級標題（小節標題） | `3` | "heading 3" | `a` |
| 目錄 1 | `11` | "toc 1" | `a` |
| 目錄 2 | `21` | "toc 2" | `a` |
| 目錄 3 | `31` | "toc 3" | `a` |
| 頁眉 | `a3` | "header" | `a` |
| 頁腳 | `a4` | "footer" | `a` |
| 目錄標題 | `10` | "TOC Heading" | `1` |

### 模式 B：英文 ID（較少見，通常來自國際模板）
標準 Heading1/Heading2/Heading3/Normal — 遵循西方模式。

### 模式 C：混合（部分中文，部分英文）
部分模板用中文名定義自定義樣式：
| 樣式用途 | styleId | w:name |
|--------------|---------|--------|
| 論文標題 | `lunwenbiaoti` | "論文標題" |
| 章標題 | `zhangbiaoti` | "章標題" |
| 正文 | `zhengwen` | "正文" |

### 如何識別是哪種模式

```bash
# 從模板提取所有 styleId
$CLI analyze --input template.docx --styles-only

# 或手動：
# unzip template.docx word/styles.xml
# 在解壓的文件中搜索 w:styleId=
```

查看前幾個 styleId。若看到 `1`、`2`、`3`、`a`、`a0` → 模式 A。
若看到 `Heading1`、`Normal` → 模式 B。

## 標準論文結構

中國高校論文遵循高度標準化的結構：

```
┌─────────────────────────────────────┐
│ 封面（Cover Page）                   │  ← 通常 1-2 頁
│   - 校名、校徽                       │
│   - 論文題目（title）                 │
│   - 作者、導師、院系、日期             │
├─────────────────────────────────────┤
│ 學術誠信承諾書 / 獨創性聲明            │  ← 1 頁
│   (Academic Integrity Declaration)   │
├─────────────────────────────────────┤
│ 中文摘要（Chinese Abstract）          │  ← 1-2 頁
│   - "摘 要" 標題                     │
│   - 摘要正文                         │
│   - "關鍵詞：" 行                    │
├─────────────────────────────────────┤
│ 英文摘要（English Abstract）          │  ← 1-2 頁
│   - "ABSTRACT" 標題                  │
│   - 摘要正文                         │
│   - "Keywords:" 行                   │
├─────────────────────────────────────┤
│ 目錄（Table of Contents）             │  ← 1-3 頁
│   - 通常在 SDT 塊內                  │
│   - 靜態示例條目                      │
│   - 目錄域代碼                        │
├─────────────────────────────────────┤
│ 正文（Body）                          │  ← 主要內容
│   第1章 緒論                          │
│   1.1 研究背景                        │
│   1.2 研究目的和意義                   │
│   第2章 文獻綜述                       │
│   ...                                │
│   第N章 結論與展望                     │
├─────────────────────────────────────┤
│ 參考文獻（References）                │  ← 樣式不同
├─────────────────────────────────────┤
│ 致謝（Acknowledgments）              │  ← 可選
├─────────────────────────────────────┤
│ 附錄（Appendices）                    │  ← 可選
└─────────────────────────────────────┘
```

## 識別模板中的區域邊界

模板包含必須替換的示例內容。以下是查找各區域的方法：

### 區域 A（前置部分）— 保留自模板
- 起始：段落 0
- 結束：第一個章標題之前的那一段
- 包含：封面、聲明、摘要、目錄
- 如何檢測結束：搜索第一個樣式為 `1`（或 Heading1）且含"第1章"或"緒論"的段落

### 區域 B（正文內容）— 用用戶內容替換
- 起始：第一個章標題（"第1章..."）
- 結束："參考文獻"標題（含）或致謝前的最後一段正文
- 如何檢測：
  ```python
  for i, el in enumerate(body_elements):
      text = get_text(el)
      style = get_style(el)
      if style in ('1', 'Heading1') and ('第1章' in text or '緒論' in text):
          zone_b_start = i
      if '參考文獻' in text:
          zone_b_end = i
  ```

### 區域 C（後置部分）— 保留自模板（或移除）
- 起始於：參考文獻之後
- 包含：致謝、附錄、末尾 sectPr

## 中文論文模板的字體預期

| 元素 | 字體 | 字號 | 磅值（pt） | w:sz |
|---------|------|------------|-----------|------|
| 論文標題 | 華文中宋 or 黑體 | 二號 or 小二 | 22pt or 18pt | 44 or 36 |
| 章標題（H1） | 黑體 | 三號 | 16pt | 32 |
| 節標題（H2） | 黑體 | 四號 | 14pt | 28 |
| 小節標題（H3） | 黑體 | 小四 | 12pt | 24 |
| 正文 | 宋體 | 小四 | 12pt | 24 |
| 頁眉 | 宋體 | 五號 | 10.5pt | 21 |
| 頁腳/頁碼 | 宋體 | 五號 | 10.5pt | 21 |
| 表格內容 | 宋體 | 五號 | 10.5pt | 21 |
| 參考文獻條目 | 宋體 | 五號 | 10.5pt | 21 |

## CJK 正文的 RunFonts

```xml
<w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman"
          w:eastAsia="宋體" w:cs="Times New Roman"/>
```

標題用：
```xml
<w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman"
          w:eastAsia="黑體" w:cs="Times New Roman"/>
```

重要：清理直接格式時，始終保留 w:eastAsia。
移除它會導致中文回退到錯誤字體。

## 中文模板的常見錯誤

1. **搜索 `Heading1`** — 中文模板用 `1`，不是 `Heading1`
2. **清除所有 rFonts** — 必須保留 eastAsia 字體聲明
3. **假設"第1章"是第一段** — 它通常是封面/摘要/目錄之後的第 100+ 段
4. **忽略目錄中的 SDT 塊** — 目錄被 SDT 包裝，不僅是域代碼
5. **錯誤行距** — 中文論文通常用固定 20pt（line="400"）或 22pt（line="440"），而非政府公文的 28pt
6. **缺少分節符** — 每個區域（摘要、目錄、正文）通常有各自的 sectPr 以實現不同的頁眉/頁腳

## 樣式映射速查

源文檔用西方 ID 而模板用中文數字 ID 時：

```json
{
  "Heading1": "1",
  "Heading2": "2",
  "Heading3": "3",
  "Heading4": "3",
  "Normal": "a",
  "BodyText": "a",
  "ListParagraph": "a",
  "Caption": "a",
  "TOC1": "11",
  "TOC2": "21",
  "TOC3": "31"
}
```

源用中文數字 ID 而模板用西方 ID 時 — 反向映射。
