# 数学类出题细则

适用：数学各分支。公式一律 KaTeX（`$…$` 行内、`$$…$$` 块级），不用 Unicode 字符拼公式。

## 能力 → 题型

### 计算题（学公式应用 / 运算）

给具体数值的计算。

- 数据设计成有理数结果：算出来 7/3、√2 保留根号都可以，避免无限小数
- 按步骤给分：列式、代入、计算、结论各占分——手滑算错和方法不会要能区分
- 答案设计陷阱：常见符号错、漏负号、定义域疏忽至少埋一处

### 推导 / 证明题（学定理理解）

证明一个命题或推导一个公式。

- 命题控制在 3–5 步可证：证明链太长变抄书检测
- 评分标准写清每一步用到的定理/性质名称
- 可以给"证明骨架"（已写好首尾步）让用户补中间——区分度比全空白证明好

### 反例构造（学概念边界）

给一个错误命题，让用户举反例驳倒它。

- 命题的错因必须单一：多处错误的命题反例不唯一，没法评
- 命题要"看起来很对"——真错得明显的命题没有检测价值

### 应用 / 建模题（学数学建模）

给现实情境，让用户建立模型并求解。

- 情境数据自洽：数字要能算出干净结果
- 评分分两段：建模（设变量、列关系式）和求解（计算）分开给分

### 一题多解题（学技巧灵活性）

给一个题，要求用两种方法求解。

- 两种方法难度要有差异（基础方法 vs 巧方法），否则没有区分度

## 坑

- 计算错 ≠ 不懂：步骤分必须能救回"方法全对手滑算错"的情况
- 不出纯查表题（"xx 定理的内容是"）；定理用"用它证明东西"来考
- 几何/函数图像类内容：图必须能被文字+公式准确描述，描述不了的改考代数性质
