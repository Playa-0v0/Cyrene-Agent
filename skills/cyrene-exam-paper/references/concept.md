# 概念类出题细则（通用，不限学科）

适用：任何学科的概念理解检测。编程概念、数学定义、物理概念先读对应学科文件，再叠加本文件的通用方法。

## 题型设计

### 概念辨析题

给两个易混淆概念，让用户说清区别。适合：看起来相似、实际不同的成对概念。

- 干扰项设计：把两个概念的定义特征互换就是最好的干扰项
- 评分要点：必须说中"区分性特征"，两个概念各自复述一遍不给全分

### 判断并解释题

给一个陈述，判断对错并说明理由。

- 陈述必须精确到能判断：模糊表述无法判对错
- 解释必答：光判对错不给分——不解释的判断就是瞎蒙检测器
- 对的陈述要有"看起来错"的地方，错的陈述要有"看起来对"的地方

### 举反例题

给一个定义/规律，让用户举一个反例或边界案例。

- 这是检测概念理解最高效的题型：背下定义的人举不出反例
- 出题前自己先验证：反例确实存在且在定义的讨论范围内
- 评分要点：反例必须真的违反定义，且能说明违反了哪一条

### 思想实验题（"如果改变 X 会怎样"）

给一个情境，改变其中一个条件，让用户推演结果。

- 适合：因果理解、机制理解
- 只改一个变量，其他条件明示不变
- 答案要有确定的推导链，不是开放讨论

## 坑

- 判断题不配解释要求 = 瞎蒙检测器，禁止
- 概念题的干扰项必须是"真实误解"（学过的人真的会这么想），凑数选项一眼假
- 一个概念考过辨析就不再考填空——同能力不重复检测
