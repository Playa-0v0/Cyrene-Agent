# 语言类出题细则

适用：英语及其他外语的词汇、语法、阅读、写作检测。语言类是"必要的记忆检测"合法的领域，但记忆题必须和运用题搭配出现。

## 能力 → 题型

### 词汇记忆（学单词 / 不规则动词 / 固定搭配）

填空、选择、配对。

- 记忆题在这类卷子里合法，但单张卷词汇记忆题不超过 1/3 分值，其余给运用题
- 干扰项用"形近词 / 音近词 / 常错搭配"：appear vs appeal、used to vs be used to
- 配对题左右列打乱顺序，防位置记忆

### 改错题（学语法精准度）

给一句话，标出错误处并改正。

- 每句只错一处；多处错误的句子评分粒度做不了
- 错误类型覆盖用户笔记里学的语法点：时态、单复数、冠词、介词搭配
- 要求写出"错在哪+改成什么"双答案，光指位置不给全分

### 翻译题（双向检测）

- 中译外：考产出能力（拼写、语序、语法）
- 外译中：考理解能力（长难句拆解）
- 评分按档：完全达意 > 意思对但生硬 > 关键词错 > 意思歪
- 句子选用户笔记里的语法点造句，不考超纲词汇

### 阅读理解（学阅读策略 / 长难句）

给一段 100–200 词短文 + 2–3 个问题。

- 问题答案必须在文中可推出：考理解不考常识和词汇量
- 至少一题是推理题（"可以推出什么"）而不是定位题（"文中说了什么"）
- 干扰项设计：文中没提但符合常识的选项最迷惑

### 情境写作（学应用表达）

给情境（邮件、通知、回复），要求写 50–120 词。

- 情境要说清目的、对象、语气约束
- 评分要点清单化：覆盖的信息点、语法准确性、得体性各占多少分

## 坑

- 纯记忆题堆满一张卷 = 默写检测器，违反蓝图原则
- 外语例句先自查语法，别出病句考语法
- 阅读文本长度控制住：200 词以上的文本是阅读速度测试，不是理解测试
