# 物理类出题细则

适用：物理各分支。物理公式是理解对象不是背诵对象。公式 KaTeX（`$…$` / `$$…$$`），计算必须带单位。

## 能力 → 题型

### 概念判断 + 解释（学物理概念）

判断陈述对错并解释。物理概念多反直觉之处，是最佳检测点。

- 优先考反直觉概念：惯性、失重、感应电流方向、参考系
- 陈述要具体："加速度大速度就大"比"加速度和速度的关系"好
- 解释必须包含物理理由，生活化直觉复述不给分

### 计算题（学公式应用）

物理过程 → 公式 → 数值。

- 单位换算独立设坑或独立给分：单位错全题错的规则要写进评分标准
- 数据设计成干净结果：g 取 10 m/s²（除非考有效数字）
- 按步骤给分：受力分析/过程判断、列式、代入、结果+单位
- 每道计算题先考"过程判断"（匀速？匀加速？守恒吗？）——过程选错公式必然错，这是物理和纯数学计算的分界

### 情境分析（学建模）

给生活场景，让用户判断物理过程并定性分析。

- 场景具体：电梯超重失重、转弯侧滑、电磁感应
- 可以只定性不计算："分析运动趋势""判断方向"

### 实验分析（学科学方法）

给实验情境，让用户分析误差来源、改进方案或推演结果。

- 误差分析考"这个误差让结果偏大还是偏小"，不是背"误差来源有哪些"
- 改进方案题给评分要点清单（控制变量、多次测量取平均）

### 估算题（学数量级感觉）

费米式估算：给少量数据估出结果的数量级。

- 结果只要数量级正确就给分
- 评分看点：建模假设是否合理，不在数值精度

## 坑

- 没带单位的数值结果不给分——写进评分标准
- 示意图：简单场景用文字精确描述（"光滑水平面上，物块 A 以 v₀ 向右"）；复杂过程建议 cyrene-diagram 的 SVG 卡片，不硬画
- 不考"XX 定律的内容是什么"；定律用"判断情境 + 应用计算"考
- 公式推导需要的前提条件（理想气体、光滑、忽略空气阻力）必须在题干明示，不搞隐藏前提
